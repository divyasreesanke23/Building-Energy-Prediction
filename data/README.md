# Dataset

The dataset file is intentionally not included in this repository. Download `ENB2012_data.xlsx` from the official UCI Machine Learning Repository page:

https://archive.ics.uci.edu/dataset/242/energy%2Befficiency

Place the downloaded file in this folder so the project path is:

`data/ENB2012_data.xlsx`

The experiment script reads the dataset from this location. Please retain the dataset's original attribution and license terms when using or redistributing it.
